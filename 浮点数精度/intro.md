计算机无法准确存储小数，只能保证小数点后几位正确。所以 <dir>
1.进行小数是否相等的判断时应当采取这种形式：
```
if(a - b < 0.01) //0.01是精度，输入你想要的精度
  ;
```

2.处理浮点数时可以考虑转化为整数后处理
```
double a;
int b = a * 100; //100是精度，输入你想要的
```

3.输出浮点数时可以用转化好的整数进行格式化输出，无需将整数再次转化为浮点数后输出，这样就避免了精度问题
```
cout << b / 100 << "." << setw(2) << setfill('0') << b % 100 << endl;
```
